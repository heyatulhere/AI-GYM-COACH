#🏋️ AI Gym Coach — AI-Powered Fitness Assistant#
An AI-powered fitness project that uses computer vision and pose estimation to help users analyze exercise movements and track workouts.
Overview
AI Gym Coach is a Python-based fitness application designed to make home workouts more interactive. It combines computer vision with an interactive interface to support exercise monitoring and movement analysis.
The project includes a web landing page and a Streamlit-based main application.
